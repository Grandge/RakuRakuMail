# らくらくメール

Gmail を保管庫として使う、サーバーを持たないチャットアプリです。
メッセージはすべて普通のメールとして送受信され、Gmail の中に残ります。
らくらくメールは、それをチャットの見た目で表示し直すビューア兼エディタです。

相手はらくらくメールを使っていなくても構いません。普通のメールとして受け取り、
普通に返信できます。その返信もチャットの続きとして表示されます。

## 特徴

- **サーバーを持ちません。** GitHub Pages から配信する静的ファイルだけで動きます
- **メールはあなたの Gmail にしかありません。** 本文をどこかに預けることはありません
- **相手を選びません。** 受け取る側にアプリは要りません
- **高齢者や IT が苦手な人が使う前提**で作っています。画面に専門用語を出しません

## 開発

```bash
npm install
npm run dev        # http://127.0.0.1:5173/RakuRakuMail/
npm test           # 単体テスト
npm run typecheck  # 型チェック
npm run build      # 本番ビルド
```

**`localhost` ではなく `127.0.0.1` で開いてください。** Google Cloud Console が
`http://localhost:5173` を OAuth の生成元として受け付けないため、`127.0.0.1` に固定しています。
ブラウザの origin は入力したホスト名がそのまま使われるので、`localhost` で開くと
`origin_mismatch` になります。

### 設定

`.env.example` を `.env.local` にコピーし、Google Cloud Console で作成した
OAuth クライアント ID を入れてください。手順は `Documents/M1実装計画.md` の
第2節（Step 0-1〜0-7）にあります。

```
VITE_GOOGLE_CLIENT_ID=xxxxxxxxxxxx-xxxxxxxxxxxxxxxx.apps.googleusercontent.com
```

クライアント ID はビルド後の JavaScript に必ず含まれるため、技術的には秘密情報ではありません。
**クライアントシークレットは使いません**（ブラウザだけで動くアプリでは秘密を保てないため）。

## 構成

```
ui/  ──▶  domain/  ──▶  gmail/  ──▶  auth/
              │            │
              ▼            ▼
           store/       mail/
```

| ディレクトリ | 役割 |
| --- | --- |
| `src/mail/` | メールの形式そのもの。**Gmail API を一切知りません。** 文字列とバイト列だけを扱う純粋関数 |
| `src/gmail/` | Gmail API の呼び出し。らくらくメールの都合（目印・独自ヘッダ）を知りません |
| `src/domain/` | 両者を繋ぐ業務ロジック。送信・取り込み・パネルの組み立て |
| `src/auth/` | Google Identity Services。トークンは**メモリ上のみ**に保持します |
| `src/store/` | 設定データの永続化（IndexedDB ＋ AES-GCM） |
| `src/ui/` | 画面。`domain/` だけを呼び、`fetch` を書きません |

`mail/` を Gmail API から切り離しているのが設計上の要点です。MIME の組み立てと解析は
試行錯誤が多く、純粋関数にしておくことで単体テストで固められます。

## 仕組み

メールをチャットに見せるための取り決めです。詳細は `Documents/要件定義書.md` 3章。

- 送信メールに**独自ヘッダ**（`X-Rakuraku-*`）と、本文末尾の**目印文字列**を付けます
- Gmail は独自ヘッダを検索できないため、Gmail の検索・フィルタで拾う手段は目印文字列だけです
- 取り込みは**会話（スレッド）単位**です。目印で会話の起点を見つけたら、そのスレッドの
  全メッセージを取り込みます。だから、相手が Gmail の画面から普通に返信しても
  （目印も独自ヘッダも無いのに）会話が途切れません
- 件名は**会話を通じて変えません**。Gmail がスレッドをまとめる際に件名も見るためです
